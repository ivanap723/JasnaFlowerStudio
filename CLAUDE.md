# Project Rules

Rules for working on Jasna Flower Studio. Read before making any change.

## Scope of changes
- Only change what was explicitly asked for.
- Never make additional changes (refactors, renames, formatting, new features, dependency updates) unless asked.
- If you notice something else worth changing, mention it instead of doing it.

## Code style
- Keep code simple and readable; it will be extended later.
- One file per page in `src/pages/`; shared parts go in `src/components/`.
